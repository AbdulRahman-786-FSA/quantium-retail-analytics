# Quantium Retail Analytics - Virtual Internship

A data analytics project completed as part of the **Quantium Data Analytics 
Virtual Internship** on Forage, simulating real-world retail analyst work.

---

## Project Overview

Analyzed retail transaction and customer data to uncover sales trends, 
evaluate store performance, and deliver actionable business recommendations.

---

## Tasks Completed

**Task 1 - Customer & Sales Analysis**
- Cleaned and merged transaction and customer datasets
- Identified sales trends and key inconsistencies in the data
- Developed metrics to analyze overall sales performance
- Visualized findings to extract actionable insights

**Task 2 - Store Trial Evaluation**
- Defined metrics to select appropriate control stores
- Compared trial stores against control stores to measure performance impact
- Used Python for data analysis and visualization

**Task 3 - Client Report**
- Structured findings using the Pyramid Principles framework
- Compiled data visualizations, key insights, and strategic recommendations
- Delivered a professional report suitable for client presentation

---

## Tools & Technologies
- Python (Pandas, Matplotlib, Seaborn)
- Google Colab
- Excel
